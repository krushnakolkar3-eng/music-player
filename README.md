# 🎵 Music Player

A modern and responsive **Music Player Web Application** built using **HTML, CSS, and JavaScript**. This project allows users to play, pause, skip, and control audio playback through an intuitive user interface.

## 🚀 Features

* ▶️ Play songs
* ⏸️ Pause music
* ⏭️ Next track
* ⏮️ Previous track
* 🔊 Volume control
* 🎵 Display song information
* 📱 Responsive design
* ⚡ Smooth user experience

## 🛠️ Technologies Used

* **HTML5** — Structure
* **CSS3** — Styling and UI design
* **JavaScript** — Audio control and functionality
